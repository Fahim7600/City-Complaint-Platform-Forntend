# TypeScript Type Definitions

Strict TypeScript interfaces and types synchronized with backend schemas (`city-complaint-platform`):
- `auth.types.ts`: User roles, tokens, auth responses
- `complaint.types.ts`: Complaint entities, status enums, priority enums, category enums
- `api.types.ts`: Standard API response shapes (`success`, `data`, `message`, `meta`, `error`)
- `service.types.ts`: Service request entities, SLA tracking
- `payment.types.ts`: Payment records, transaction statuses
