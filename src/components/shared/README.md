# Shared Components

Reusable, domain-specific UI components across the City Complaint & Service Platform:
- `StatCard`: Key metrics and statistics cards
- `StatusBadge`: Complaint/request status indicators with status colors
- `DataTable`: Generic data tables with sorting and pagination
- `EmptyState`: Clean empty states for tables, lists, and search results
- `SearchInput`: Debounced search input with clear button
- `PageHeader`: Consistent title, description, and action button bar
- `ConfirmationDialog`: Destructive action and confirm modal dialogs
